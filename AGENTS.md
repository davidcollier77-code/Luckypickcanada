# Agent Rules & Guidelines

## Library Documentation (Context7)
- Always use Context7 MCP / documentation search when looking up library APIs, Next.js patterns, Tailwind classes, or Cloudflare Worker configurations.
- When retrieving documentation, use exact library IDs where applicable (e.g., `/vercel/next.js`, `/cloudflare/workers`).
- For authenticated priority rate limits, include the header `Authorization: Bearer <CTX7_API_KEY>` when querying Context7 tools.
