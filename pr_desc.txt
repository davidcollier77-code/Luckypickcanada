## 🛡️ Gemini: Improve Gemini PR Review Quality and Introduce a Select-Findings-Then-Fix-Selected Workflow

### What
- Updated the Gemini PR Reviewer formatting in `.github/scripts/gemini-reviewer.cjs` to include a new action checkbox for "Fix selected findings".
- Improved findings list output to include a checkbox next to each finding so the human developer can select which ones they want fixes for.
- Added logic in `parseReviewAction` and the main loop to safely handle processing of selected finding items, making sure empty selection defaults to safely doing nothing with a clear comment.
- Reused `parseSelectedIds` internally in `parseReviewAction` safely.
- Wrote new regression unit tests in `gemini-reviewer-context.test.ts` to assert that selecting findings correctly resolves the action intent, including empty cases.
- Ensured existing features (`repair all`, `repair one`) remain completely intact.

### Why
- Provides the owner the power to select specifically which AI findings actually warrant targeted AI fix suggestions, reducing noise and false positives from large "repair all" queries.
- Improves workflow by providing a checklist approach, satisfying the master work request to refine how we interact with the findings generated by Gemini in GitHub.
