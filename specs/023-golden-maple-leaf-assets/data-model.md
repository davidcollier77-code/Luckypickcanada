# Data Model — Premium Golden Maple-Leaf Assets

There is no new persistent or user-entered data model for this feature.

The only resources are static public image files:

- `golden-maple-leaf.avif`: preferred compact raster source with alpha transparency.
- `golden-maple-leaf.webp`: second-choice raster source with alpha transparency.
- `golden-maple-leaf.svg`: compatibility fallback source.

The GoldenLeaf component exposes only its existing presentation inputs (`className` and `style`); no API, database, client storage, or server contract is introduced.
