## 2026-09-05 - Fix Github Actions validation workflow
**Learning:** For Github actions where `pnpm install` fails due to lockfile versioning and frozen-lockfile flag matching, use `pnpm/action-setup@v4` in the github workflow. Since `packageManager` is defined in `package.json`, do not specify the `version` field in the action config; otherwise `ERR_PNPM_BAD_PM_VERSION` error happens as Github Action runner downloads multiple pnpm versions (the one defined in `package.json` vs the one specified in the config).
**Action:** Replaced `npm ci` with `pnpm install --frozen-lockfile` and added `pnpm/action-setup@v4` without `version: 9`. Regenerated `pnpm-lock.yaml` correctly using `pnpm install` with ignore scripts config set to true.
