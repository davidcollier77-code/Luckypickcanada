## 2025-05-24 - Payment button loading state
**Learning:** For forms that trigger native navigation without `event.preventDefault()` (like Stripe Checkout POSTs), the standard React state reset in a `finally` block won't execute if the page successfully unloads. However, if the page hangs or the user uses the back button (bfcache), the button might remain permanently stuck in a "Please wait..." disabled state.
**Action:** Used a `pageshow` window event listener combined with `e.persisted` to reset the `isSubmitting` state when navigating back via bfcache. Also added a fallback `setTimeout` to reset the state if the form submission hangs but fails to navigate within a reasonable window (8 seconds).
