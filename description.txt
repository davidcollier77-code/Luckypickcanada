## Description

This PR implements the requested Google Analytics 4 integration into the Lucky Pick Canada Next.js application using the provided Measurement ID.

**Changes Include:**
- **Content Security Policy (CSP):** The `Content-Security-Policy` header in `next.config.mjs` was updated to securely whitelist Google Analytics and Google Tag Manager endpoints.
- **Google Tag Injection:** The GA4 integration was implemented directly inside `app/layout.js` utilizing `next/script` (`strategy="afterInteractive"`). This ensures standard pageview tracking without causing duplicate fires across client-side router navigations in the SPA.
- **Spec Kit Governance:** Generated required `spec.md`, `plan.md`, and `tasks.md` documents underneath the `ga4-integration` directory to align with task execution requirements and validation checks.

The implementation honors the 495MB build capacity limits, strictly stays within the allowed environment scope without initializing unapproved accounts, and ensures no other application modules, behaviors, or UI components are affected.
