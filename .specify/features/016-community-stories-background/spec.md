# Community Stories Background Fix Spec

## Problem
The Community Stories container on the homepage allows underlying content to bleed through its semi-transparent background (`bg-black/20`).

## Requirement
Update the container to use a completely opaque, custom midnight-blue starfield background. The background should be provided by an optimized WebP image. The container's foreground content must remain visible and unobstructed, and surrounding website content must be unaffected.
