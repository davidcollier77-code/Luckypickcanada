# Requirements Quality Checklist: Gemini Review Depth

- [x] The reviewer goal prioritizes bugs and real regressions instead of comment volume.
- [x] The specification identifies relevant all-in-one review categories.
- [x] The specification explains how to handle uncertainty and avoid speculative findings.
- [x] The specification distinguishes code inspection from rendered visual QA.
- [x] The specification defines a testable ceiling for findings without requiring the limit to be filled.
- [x] The specification preserves provider identity, fallbacks, secret handling, and review-only behavior.
- [x] The specification defines regression-test and live-review acceptance evidence.
- [x] The specification explicitly records what remains unknown until CI/live verification.
