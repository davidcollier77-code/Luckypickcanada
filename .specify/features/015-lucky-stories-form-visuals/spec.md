# Feature Specification: Lucky Stories Form Visual Polish

## Overview
Improve the appearance of the existing Lucky Stories / Community Stories submission form on LuckyPickCanada.ca so it matches the visual identity of the Lucky Map page.

## User Value
The form will present a premium, cinematic experience that aligns visually with the Lucky Map page.

## Functional Requirements
- Visual improvements only. No changes to functionality.
- The form must visually resemble a starry Milky Way setting with a premium translucent midnight-blue panel.
- Elegant cream typography, gold borders and controls, and a prominent gold submit button.

## Success Criteria
- The form matches the provided design reference in layout, color, and spacing.
- The starry background shines through the translucent panel.
- No existing behavior or functionality is changed or broken.

## Out of Scope
- Functional changes to the form, submission logic, or validation.
- Changes to the Cloudflare Turnstile integration logic.
