### <MotionConfig />

Source: https://motion.dev/docs/vue-motion-config

Sets configuration options for all child motion components, including fallback transitions, reduced motion policies, and CSP nonces.

```APIDOC
## MotionConfig

### Description
The `<MotionConfig>` component can be used to set configuration options for all child `motion` components.

### Usage
```vue
<script setup>
  import { motion, MotionConfig } from "motion-v"
</script>

<template>
  <MotionConfig :transition="{ duration: 1 }">
    <motion.div
        :initial="{ opacity: 0 }"
        :animate="{ opacity: 1 }"
      />
  </MotionConfig>
</template>
```

### Props
- **transition** (object) - Optional - Define a fallback transition to use for all child `motion` components.
- **reducedMotion** (string) - Optional - Default: `"never"`. Sets a site-wide policy for handling reduced motion. Options: `"user"` (respect device setting), `"always"` (enforce reduced motion), `"never"` (don't respect reduced motion). When on, transform and layout animations are disabled while other animations persist.
- **nonce** (string) - Optional - If using a Content Security Policy with a nonce attribute, passing it here allows style blocks generated by Motion to adhere to the policy.
```

### resize(target?, callback)

Source: https://motion.dev/docs/resize

Monitors and reacts to size changes in the viewport or specific HTML/SVG elements using a shared ResizeObserver. Returns a cleanup function to remove attached listeners and stop observation when no listeners remain.

```APIDOC
## resize(target?, callback)

### Description
Reacts to size changes on the viewport or any element via a shared `ResizeObserver`.

### Import
```javascript
import { resize } from "motion"
```

### Syntax
```javascript
// Viewport tracking
resize(callback)

// Element tracking
resize(target, callback)
```

### Parameters
- **target** (string | Element) - Optional - An element or CSS selector targeting HTML or SVG elements to observe.
- **callback** (function) - Required - The callback function executed when size changes occur.
  - When tracking the viewport: `({ width, height }) => void`
  - When tracking elements: `(element, { width, height }) => void`

### Returns
- **stop** (function) - A cleanup function that removes the attached listener when called.

### Examples

#### Viewport Tracking
```javascript
const stop = resize(({ width, height }) => {
  console.log("Viewport size:", width, height)
})

// Stop observing
stop()
```

#### Element Tracking
```javascript
const stop = resize(".drawer", (element, { width, height }) => {
  console.log(element, "is now", width, height)
})

// Stop observing
stop()
```
```
