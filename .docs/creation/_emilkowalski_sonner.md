### Sonner Quickstart Implementation

Source: https://github.com/emilkowalski/sonner/blob/main/_autodocs/00-START-HERE.txt

Basic installation, import, component setup, and usage examples for the Sonner library.

```javascript
// 1. Install
npm install sonner

// 2. Import
import { Toaster, toast } from 'sonner'
import 'sonner/dist/styles.css'

// 3. Add component
<Toaster />

// 4. Use anywhere
toast('Hello!')
toast.success('Done')
toast.error('Failed')
```
