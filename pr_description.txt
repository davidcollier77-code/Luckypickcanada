## 🔴 LUCKYPICKCANADA — LUCKY METER CINEMATIC FINALE REPAIR

This PR implements the requested surgical fix for premature cinematic termination across the Lucky Meter tiers in `components/DailyResonance.tsx`.

### A — Verified Root Cause
The canvas animation loop was previously hard-coded to terminate unconditionally via `const isHardStop = elapsedMs > 5500;`. This abruptly aborted the visual decay and forcefully stopped all audio streams (including the long-running White Willow particles), regardless of whether the particles had finished dissipating on screen. Furthermore, the White Willow effect incorrectly shared standard audio loops instead of having a distinct, dedicated firework audio profile.

### B — Approved Scope & Execution
- **Removed Premature Cutoffs:** The 5500ms hard stop has been removed. The loop will now cleanly terminate only once the tracking arrays (`particles`, `meteors`, `lightningStrikes`) are demonstrably empty, allowing effects to finish naturally.
- **Dedicated White Willow Audio:** Integrated a properly licensed "Firework Crackle" asset (`mixkit-firework-crackle.mp3` from Mixkit under the Free Commercial-Use License) as a distinct audio stream exclusively for the White Willow tier.
- **Audio/Visual Synchronization:** Bound the volume/fade behavior of `willowCrackle` strictly to the tracking opacity values of active `willow` particles. As the particles visually fade, the crackle audio smoothly decreases synchronously.
- **Protected Behaviors Preserved:** All existing Howler.js implementation specifics, normal tier sounds (meteors, lightning, standard fireworks bursts), structural animations, and accessibility features (`prefers-reduced-motion`) have been strictly preserved.

### Verification Results
1. Build `pnpm run build` succeeds completely.
2. `vitest` tests pass with no regressions.
3. `./jules-verify.sh` automated checks pass.
4. Diff verified to ensure no external, unauthorized systems were touched.
