**What:**

**Impact:**
- Better network prioritization and Time to Interactive due to the `api.js` script downloading concurrently with core HTML, rather than waiting for client-side evaluation.
- Solves a hard regression blocking the CI pipeline.
- Reduces parsed CSS slightly.
